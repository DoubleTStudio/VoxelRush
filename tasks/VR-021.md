# Task: VR-021 — Seeded terrain generator + golden hashes

## Goal
Deterministic procedural terrain pinned by generator version. DoD (BACKLOG): reproducible.

## Prerequisites / relevant docs
VR-020 (chunk data). VOXEL_ENGINE (Deterministic generation: "never assume floating point noise exactly matches across CPU architectures: canonical hashes/tests"), ADR-003, CONTRACTS (ChunkSnapshot contentHash), QUALITY_GATES (same seed/version → matching canonical chunk hashes).

## In scope / out of scope
In: integer/fixed-point heightmap generator v1 (grass/dirt/stone, air above), `ChunkHash` (canonical content hash), golden hashes incl. negative coordinates, reproducibility/continuity/layering tests.
Out: biomes, caves, decorations (trees/rocks), world bounds/launch-map shape, generation scheduling/streaming (VR-023), material catalog (DES-001).

## Public interfaces and contracts
- `TerrainGenerator(long seed)`: `Version = 1`, `SurfaceHeight(x, z)`, `GenerateBlocks(coord)`, `Generate(coord)`. 4 octaves of hashed-lattice value noise (SplitMix64) with smoothstep weights, all 16.16 fixed point: no floating point, so output is bit-identical across CPUs/runtimes.
- `ChunkHash.Compute(chunk)`: FNV-1a 64 over schema version, generator version, coordinate and the 4096 effective blocks (consistency check, not tamper resistance).
- `BlockIds`: Air 0, Grass 1, Dirt 2, Stone 3; `ChunkData.CopyEffectiveBlocks`.
- Rule: any change to generator output requires bumping `TerrainGenerator.Version` and regenerating golden hashes (a pinned test enforces the version).

## Tests (`Tests/Domain/World/TerrainGeneratorTests.cs`)
6 golden hashes (incl. (−1,0,−1), (−20,−1,15), (1000,2,−1000)); pinned version; reproducible across instances (49 chunks); seed sensitivity (+ golden for seed 54321); column layering; continuity across chunk borders incl. negative; height band; hash depends on content (edit + revert restores it) and coordinate.
