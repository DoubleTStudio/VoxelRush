## Implementation steps
1. Domain job: `actions/setup-dotnet` from `global.json`, `tools/test.sh domain`.
2. `unity-license` gate job: Unity jobs show as skipped plus a warning when secrets are missing.
3. Unity jobs use `game-ci/unity-test-runner` v4.3.2 and `game-ci/unity-builder` v4.8.2 (v6 downloads an unpinned CLI at runtime, so not used), images `unityci/editor:ubuntu-6000.3.26f1-*` (tags verified to exist).
4. Builds call `VoxelRush.Editor.BuildEntryPoints.*` with `manualExit`, so project configuration validation gates every build.
5. Server smoke reuses `tools/smoke-server.sh` on the native x86-64 runner (covers the Rosetta gap from VR-001).
6. iOS only on `main`/manual: Xcode project from Linux, tarred, compiled unsigned on `macos-15`.

## Failure modes / security concerns
- `permissions: contents: read`; secrets passed only as step env to the Unity steps; actions pinned to SHAs.
- `concurrency` cancels superseded runs; every job has `timeout-minutes`.
- Library cache keyed on `packages-lock.json` + editor version, per build target.
