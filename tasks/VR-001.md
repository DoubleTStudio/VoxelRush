# Task: VR-001 — Unity URP project, platform settings, asmdefs, pinned editor/packages

## Goal
Bootstrap a Unity 6 LTS URP project for Android/iOS with a Linux dedicated server build target, assembly boundaries from SYSTEM.md and the test infrastructure.
DoD (BACKLOG): editor opens + Android smoke scene.

## Prerequisites / relevant docs
README, AGENTS, SYSTEM, DECISIONS (ADR-001, ADR-002), DEPLOYMENT (Bootstrap), QUALITY_GATES (Every PR, CI), CONTROLS_ASSETS (landscape). Decisions recorded in `docs/adr/ADR-012-bootstrap-pins-and-assembly-layout.md`.

## In scope / out of scope
In: project + pins, URP assets, platform settings as code, asmdefs, Client/Server scenes, server host entry point, test tiers, build/test/smoke scripts.
Out: networking/NGO and Docker image (VR-002), GitHub Actions (VR-003), input maps (VR-010), quality presets (VR-071), release signing (VR-081).

## Public interfaces and contracts
- `VoxelRush.Core.SimulationConstants`: `ServerTickRate = 30`, `MaxPlayersPerServer = 8`, `ProtocolVersion = 1`.
- `VoxelRush.Core.Hosting.ServerLaunchOptions.Parse(args)`: `-port 1..65535` (default 7777), `-maxPlayers 1..8`, `-smokeTestTicks 1..18000`. Unknown args are ignored; invalid values return errors and never throw.
- `VoxelRush.Core.Diagnostics.LogEvent.Format`: logfmt lines; values are quoted/escaped so they can't inject fields or lines.
- Server process: exit `0` success/smoke complete, `2` invalid arguments. Events `server_started`, `server_smoke_test_passed`, `server_invalid_argument`, `server_stopping`.
- Client: `client_smoke_ready` event from `ClientSmokeProbe`.
- Batch entry points: `VoxelRush.Editor.BuildEntryPoints.{ConfigureProject, BuildAndroid, BuildIos, BuildLinuxServer, BuildMacServer}`; `-buildOutput <path>`, `-developmentBuild`.

## Implementation steps
1. Installed Unity 6000.3.26f1 with Android/iOS/Linux Server/Linux IL2CPP (+ Mac Server for local runs).
2. Project settings/URP assets taken from the editor's bundled URP template (`com.unity.template.3d-cross-platform-17.0.14`); sample content, tutorial and extra packages removed; `productGUID` regenerated.
3. Manifest trimmed to URP, Input System 1.20.1, Test Framework, uGUI, IDE packages and the needed modules (no analytics, XR, terrain, 2D, NavMesh, multiplayer center).
4. 8 runtime/editor asmdefs + 3 test asmdefs; `-nullable:enable` via `Assets/csc.rsp`.
5. `ProjectConfiguration.Apply/Validate` for IDs, landscape-only, IL2CPP/ARM64, Android min API 26 / target auto, iOS 15.0, Linear, Input System only, URP, build scenes.
6. Scenes generated once via a temporary batch script (not committed).

## Failure modes / security concerns
- Invalid server args fail fast with exit 2 rather than starting with defaults.
- Smoke runs are bounded (`MaxSmokeTestTicks`, script timeout) so a hung player fails CI instead of stalling it.
- Log values are escaped against log-line injection.
- No secrets in the project; signing keystores/profiles are git-ignored.

## Unit tests
- Domain (engine-free, runs in Unity and on .NET): `ServerLaunchOptionsTests`, `LogEventTests`.
- EditMode: `ProjectConfigurationTests` (settings drift), `AssemblyArchitectureTests` (engine-free domain, no editor/test refs from runtime, server/presentation isolation, no cycles), `BuildSceneTests`.

## Integration and performance tests
- PlayMode: `ClientSceneSmokeTests` boots the Client scene, asserts URP and readiness.
- Server smoke: `tools/smoke-server.sh` (exit 0 after N ticks; exit 2 on invalid args).
- Performance: not applicable yet (no hot path). Observed 60 server ticks in ~2.6 s including startup, consistent with the 30 Hz frame cap.

## Definition of done
- [x] Editor opens the project and compiles all assemblies with 0 errors / 0 warnings (batch mode).
- [x] Android smoke scene: Client scene boots on URP in PlayMode; Android APK builds.
- [ ] Android smoke scene **on a device**: not run, no device attached (`adb devices` empty).
- [x] Pinned editor and packages committed (`ProjectVersion.txt`, `manifest.json`, `packages-lock.json`).

- Rollback: revert the commit; no data or contract migrations.
