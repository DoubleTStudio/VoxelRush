# Task: DES-010 — Player-built anchor graph

## Goal
Know which player-built blocks lose support after a removal. DoD (BACKLOG): disconnected component detection.

## Prerequisites / relevant docs
DES-004 (server commits), VR-031 (authority). DESTRUCTION (Structure: natural terrain exempt from mass collapse; player-built components connected to anchors; bounded BFS on deletion; union-find alone insufficient for deletions).

## In scope / out of scope
In: `IStructureWorld`, `AuthorityStructureView` (player-built = differs from the generated base; protected blocks and natural terrain are anchors; unloaded chunks count as support), `SupportAnalyzer` (bounded 6-neighbour BFS: Supported / Disconnected + component / Unresolved; `AfterRemoval` per neighbour with component de-duplication).
Out: scheduling work across ticks, caps and blocked regions (DES-011), removing collapsed components and their debris (DES-011), collider priority (DES-012), material-based load limits (cantilever strength) — not in the spec.

## Design notes
- Support is face connectivity to any non-player-built solid block, sideways included (an overhang glued to a cliff holds).
- A search stops at the first anchor; a component is reported only when fully explored. Running out of budget returns Unresolved with no partial component, so the caller can never collapse a structure on incomplete information.
- Unloaded neighbours count as support: never collapse what the server can't see.

## Tests (`Tests/Domain/Destruction/StructuralSupportTests.cs`)
Tower cut at the base → the rest is one disconnected component; bridge cut in the middle → both halves anchored; bridge losing both pillars → one component (pillar remnants + deck); T split → one component, then two separate arms with no duplicates; natural terrain exempt; sideways attachment to terrain anchors; structure traced across ≥3 chunks; unloaded chunk supports; protected blocks anchor; budget exhaustion → Unresolved (then Supported with enough budget); air/natural starts cost nothing.
