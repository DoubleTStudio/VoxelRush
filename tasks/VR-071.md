# Task: VR-071 — Android/iOS device quality presets, thermal soak

## Goal
Quality that fits each device and stays there when it heats up. DoD (BACKLOG): target tier benchmark.

## Prerequisites / relevant docs
VR-001 (URP mobile asset), VR-070 (meshing profile), DES-005 (debris pool). QUALITY_GATES (device-tier benchmark on real Android and iOS: low tier 30 fps, high tier 60 fps when sustainable; p95/p99 frames, memory, GC, thermal; record models and duration), VOXEL_ENGINE (chunk cache capped by device tier).

## In scope / out of scope
In (engine-free, `Core/Performance`): `QualityTier`, `QualityPresets` (render scale, shadow distance, target fps, streaming radius, debris pool, MSAA, chunk cache), `DeviceProfile.Classify`, `AdaptiveQuality` (3 s windows; step down when p95 > budget × 1.15 or thermal headroom ≥ 0.85; step up after 30 s with p95 < 70% of the next tier's budget; never above the classified tier; ≥ 10 s between changes), `FrameStats`. Unity: `QualityController` (runtime copy of the URP asset, `-qualityTier` override, debris pool per tier), `ThermalProbe` (Android 11+ `getThermalHeadroom`), `BenchmarkRunner` (`-benchmarkSeconds`, orbiting camera over voxel terrain with debris bursts, JSON result). All in `Client.unity`.
Out: running the benchmark on devices (blocked: no devices here), iOS thermal state (needs a native plugin), wiring streaming radius/chunk cache to a client streamer (the client doesn't stream the world yet), the device tier table.

## Design notes
- The project URP asset is never modified at runtime: the controller swaps in a clone and restores the original on destroy (editor sessions and tests stay clean).
- Classification thresholds are provisional placeholders until the tier table exists; a wrong starting guess is corrected downward within one window.

## Bug found by tests (fixed)
`AdaptiveQuality` reset its "stable since" time whenever a window emptied, so it could never step back up.

## Tests
- Domain (`QualityTierTests`): preset targets; classification table; over-budget steps down one tier at a time with the 10 s minimum interval; thermal headroom steps down immediately; stable headroom steps back up after 30 s but not above the ceiling; on-budget stays put; frame-stat percentiles/fps/over-budget.
- PlayMode (`QualityBenchmarkTests`, loads `Client.unity`): presets reach a runtime URP copy (render scale, shadows, fps) and the project asset is untouched; the benchmark renders terrain and writes its JSON.
