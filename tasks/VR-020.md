## In scope / out of scope

Out: terrain generation and golden hashes (VR-021), meshing (VR-022), streaming (VR-023), block HP (DES-001), serialization/snapshots (VR-032, SAVE-003), material catalog.

## Public interfaces and contracts
- `ChunkMath`: `Size = 16`, `Volume = 4096`, `FloorDiv`/`FloorMod` (arithmetic shift/mask: floors negatives), `ToChunk`, `ToLocal`, `ToWorld` (rejects |chunk| > `MaxChunkCoordinate`), `FaceNeighboursAffected` (0–3 chunks; allocation-free via `Span`).
- `LocalBlock.Index = x + 16 * (z + 16 * y)`; `TryFromIndex` for untrusted wire values.
- `ChunkData(coord, generatorVersion ≥ 1, baseBlocks[4096], revision, schemaVersion = 1)`: base copied and never mutated; `Set` returns false and keeps the revision on no-op; restoring the base value drops the edit (revision still advances); `Edits` in ascending index order.
- Engine-free (`VoxelRush.World`, `noEngineReferences`); compiled into the .NET domain harness alongside Core.

## Tests (`Tests/Domain/World/ChunkBoundaryTests.cs`)
Floor division/mod incl. −1, −15, −16, −17, −32, −33, int.MinValue/MaxValue; 20,000 seeded random signed round trips across the addressable world; blocks adjacent across zero land in adjacent chunks; out-of-world chunks rejected; index layout + all 4096 round trips; untrusted indices −1/4096/65535/int.MinValue rejected; per-axis bounds; face neighbours for interior/edge/corner incl. negative chunks; equality/hashing; ChunkData base/edit/revision/no-op/revert/order/defensive copy/validation; 4096-byte budget.
