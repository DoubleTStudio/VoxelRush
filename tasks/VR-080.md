## Tests
- Domain: `JoinTicketTests` (round trip, forged key, every single-byte tamper, expired/not-yet-valid/malformed, short keys, verifier replay/wrong world/expiry forgetting); `TicketAdmissionTests` (ticket admits with player id and role; session payload refused in ticket mode; forged/wrong world/replayed/expired refused without taking slots; same player twice refused, reconnect with a fresh ticket keeps the player id; dev server refuses tickets and gives sessions editor role); payload v3 encodings; `-worldId` parsing.
- **API (DoD, `backend/VoxelRush.Api.Tests`, real PostgreSQL 17 + S3 store via Testcontainers, 27 tests)**: protected endpoints need tokens; forged/tampered/`alg:none`/garbage tokens refused; access tokens expire; refresh rotation and reuse revokes the family; refresh expiry; private worlds invisible to strangers (404 even with invalid payloads), only owners change worlds or members; editors can't administer; public worlds admit visitors only; removed members fall back to visitor; quota; SQL-injection/XSS/whitespace/over-long/control-char names and bad visibility rejected; oversized bodies rejected; tickets verify once on a game-server verifier, fail for other worlds and other keys; internal endpoints need the service token (a player token isn't one); snapshot upload → presigned PUT (tampered URL refused) → commit verifies SHA-256 → presigned GET returns the bytes; wrong content never indexed; committed snapshots immutable; bounded coordinates/revisions/sizes; storage keys contain only ids and integers; auth rate limit returns 429.
- **End to end** `tools/smoke-auth.sh native`: PostgreSQL + API containers, a server with `-worldId`; the owner joins with an API ticket and builds (6/6 accepted); a public-world visitor joins but every edit is refused `not_permitted`; a replayed ticket (`ticket_replayed`), a forged one (`ticket_invalid`) and none (`ticket_required`) are refused at the handshake; the ticket key appears in no log.

## Issues found during validation (fixed)
- JWT lifetimes were checked against wall time (IdentityModel), ignoring the app clock: now validated with the injected clock.
- Member changes validated the payload before access, answering a stranger with 400 instead of 404 (an existence leak): access is checked first.
- MinIO images are no longer on Docker Hub; tests use SeaweedFS's S3 API with an identity configured so signatures are enforced.
- Unity's NUnit compares tuples containing `ushort`/`byte[]` differently from .NET's; payload tests compare fields individually.
