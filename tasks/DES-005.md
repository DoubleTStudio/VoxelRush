# Task: DES-005 — Debris VFX pooling

## Goal
Cosmetic debris for destroyed blocks that costs a fixed budget and never touches physics or the network. DoD (BACKLOG): no networked debris rigidbodies.

## Prerequisites / relevant docs
DES-004 (explosions), VR-033 (replica). DESTRUCTION (Cosmetic debris: client-local pooled particles/meshes, no per-block synchronized Rigidbody; explosion effects distinct from the authoritative voxel batch), PERFORMANCE (mobile budgets).

## In scope / out of scope
In: `ClientWorldReplica.BlockChanged` (old/new type per delta change, not for snapshots), `DebrisPlanner` (engine-free: pieces per block, per-frame cap, xorshift randomness), `DebrisEffects` (Presentation: fixed pool of renderer-only cubes moved ballistically, oldest reused when full, `Attach(replica)`).
Out: adding `DebrisEffects` to `Client.unity` with a URP material (together with rendering the synced plot — the client doesn't draw it yet, ADR-016), atlas-textured debris, explosion flash/sound event message, device profiling.

## Design notes
- Pieces are plain `MeshFilter` + `MeshRenderer` children: no `Rigidbody`, `Collider` or `NetworkObject`, so debris can't affect gameplay or bandwidth. Motion is integrated in `Update` (gravity, spin, shrink, 1.2 s lifetime).
- Budget: 3 pieces per block, 96 per frame, pool 192 by default; a 256-block blast shows the nearest ~32 blocks' worth and recycles instead of allocating.
- Debris is driven by replicated removals, so every client shows it for edits, collisions and explosions alike, including late deltas; snapshots (joins) spawn nothing.

## Tests
- Domain (`DebrisPlannerTests`): per-block count and frame cap with next-frame reset; pieces start inside the block and fly up; replica reports delta changes with old/new type and nothing for snapshots.
- PlayMode (`DebrisEffectsTests`): **DoD** — a real server blast replicated to a client replica drives the effects: 96 pieces (frame cap), ≤ 64 active (pool), 32 recycled; the whole hierarchy has no Rigidbody/Collider and only Transform/MeshFilter/MeshRenderer/DebrisEffects components. Pieces fall and expire; steady-state spawn + tick **allocate no GC memory**; detach stops listening.
