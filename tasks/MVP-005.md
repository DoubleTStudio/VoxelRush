# Task: MVP-005 — Block palette in phone build mode

## Goal
Players choose what to build instead of always placing brick.

## Changes
- `PhoneBuilder`: in Place mode, a palette row under the status box offers Brick, Stone, Wood, Concrete, Glass and Metal. Protected and reinforced blocks stay server-placed and are not offered.
- Taps on the status box or palette count as UI, not world aims. The panel rectangle is tracked in GUI coordinates, because IMGUI is invisible to the uGUI HUD check.

## Verification
- PlayMode 35/35 (palette selection; protected blocks rejected).

## Risks / rollback
