## Public interfaces and contracts
- Handshake payload: `protocolVersion` as uint16 little-endian, exactly 2 bytes (`ConnectionPayload`).
- Rejection reasons sent to clients: `malformed_payload`, `protocol_mismatch`, `server_full`, `handshake_timeout`.
- `ConnectionGate` (Core): `TryAdmit`, `MarkConnected`, `Release`, `ExpirePending`, `Count` (reserved), `ConnectedCount`.
- `VoxelRush.Networking.ServerNetwork.Start(port, maxPlayers)` / `ClientNetwork.Connect(endpoint)`: the only NGO-facing API.
- Server: new exit code `3` (listen failed); events `server_listening`, `client_connected`, `client_disconnected`, `client_rejected`, `client_pending_expired`.
- Client: `-connect host:port`, `-smokeTestSeconds N`; exit `0` / `2` invalid args / `3` connect failed or rejected; events `client_connecting`, `client_connected`, `client_disconnected reason=...`, `client_connect_timeout`.
- Build scripts: `client-linux`, `client-mac` targets; `tools/smoke-join.sh native|docker`.
- Docker: `docker/server/Dockerfile` (amd64, digest-pinned Ubuntu 24.04, uid 10001, read-only install dir, UDP 7777), `docker/compose.yaml`.

## Failure modes / security concerns
- Malformed/oversized payloads and protocol mismatches rejected before a slot is taken.
- Slots reserved at approval: concurrent approvals can't exceed the cap.
- Half-open handshakes expire after 10 s; a late handshake on an expired slot is disconnected (no bypass of the cap).
- Graceful client shutdown frees slots immediately.
- Container: non-root, no writable install dir, no extra packages, `cap_drop: ALL`, `no-new-privileges`, read-only root fs in compose.
- Not yet: authentication/authorization of who may join (join tickets, VR-080). Anyone reaching the port with the right protocol version can take a slot.

## Bugs found during validation (fixed)
1. NGO registers message types after scene `Awake`; starting the server in `Awake` threw `Allowed types ... Count: 0`. Networking now starts in `Start`.
2. Builds made right after a server build serialized scenes against server-compiled editor scripts, so client players shipped with missing scripts. `tools/build.sh` now starts Unity on the exact `-buildTarget`/`-standaloneBuildSubtarget`, and `BuildEntryPoints` refuses to build on a mismatch.
3. NGO scene sync made clients wait for `Server.unity`; scene management is disabled (ADR-014).
4. `Dispose` touched an already-destroyed `NetworkManager` at app exit; both wrappers now dispose idempotently.
5. Clients quit before NGO sent the disconnect; the server held slots until transport timeout. Clients now finish shutdown before quitting, and the join test asserts both server-side disconnects.
