# Task: CI-001 — Fast PR gate, full suite on main

## Goal
PR feedback in ~15 min instead of ~45, without losing coverage before a release.

## Changes (`.github/workflows/ci.yml`)
- **Fast gate on PRs:** domain tests and the crash test, API tests, EditMode, PlayMode, Linux server and bot builds, the server smoke test, and the join, drive, world, race (4 racers) and auth end-to-end tests.
- **Full suite on main, manual runs, and PRs labelled `full-ci`:** adds the Android APK; the progression, lease, recovery-drill and chunk-cache tests; loss, destruction stress and the 8-bot load test; and iOS (main/manual only). Adding the label triggers a run.
- **Backend/docs-only PRs** (`backend/`, `docs/`, `tasks/`, `docker/api/`, `*.md`) skip the Unity job and its single-license queue.
- **Fast-gate Unity install** has only the Linux modules; the Android SDK/NDK/JDK make up most of the ~8 min install.

## Not done
A self-hosted runner on a developer machine: the repository is public, and GitHub advises against self-hosted runners for public repositories because fork PRs could run code on the machine.

## Verification
- actionlint clean; changed-files filter checked against backend-only, mixed, docs-only, workflow and tools changes.
- Takes effect on the PR that adds it.

## Risks / rollback
A failure that only the full suite catches now shows up on main after merge rather than on the PR; add `full-ci` to risky PRs. Rollback: revert.
