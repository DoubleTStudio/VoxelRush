# Task: VR-022 — Cull/greedy meshing + atlas

## Goal
Render voxel chunks efficiently. DoD (BACKLOG): no per-voxel GameObjects.

## Prerequisites / relevant docs
VR-020/VR-021. VOXEL_ENGINE (Meshing, Memory: no per-block GameObject, Tests: greedy mesh face count, dirty neighbour), AGENTS hard rule (never one GameObject per voxel), CONTROLS_ASSETS (original art, license provenance), skills/voxel-engine.

## In scope / out of scope
In: engine-free greedy mesher with face culling across chunk borders, atlas tile mapping per block/face, Unity mesh upload, one GameObject per non-empty chunk, atlas URP shader, procedural placeholder atlas, preview scene, render capture.
Out: streaming/budgets/colliders (VR-023), Burst/jobs meshing (VR-070), ambient occlusion, transparent blocks, special ramps/boosts (authored meshes), final art.

## Public interfaces and contracts
- World (engine-free): `ChunkMesher(BlockAtlas).Build(chunk, neighbours[+X,−X,+Y,−Y,+Z,−Z], ChunkMeshData)`. Missing neighbours count as air (no holes; the neighbour rebuilds when it loads). `ChunkMeshData`: positions/normals/block-unit UVs/tile per vertex, CCW-front indices; `BlockAtlas` (`IsOpaque`, `Tile(block, face)`, `Default`: grass top/side, dirt, stone).
- Presentation: `ChunkMeshBuilder.Upload(data, mesh)` (UV0 block units, UV1 tile; 16/32-bit index switch), `VoxelTerrainView` (region build/rebuild, `ChunkObjects`).
- Assets: `Shaders/VoxelAtlas.shader` (URP, `frac` tiling, point sampling, main-light shading), `Art/VoxelAtlas.png` (procedurally generated, no third-party art) + `VoxelAtlas.mat`, `Scenes/VoxelPreview.unity` (dev scene), `docs/screens/VR-022-voxel-preview.png`.
- `tools/unity.sh`: `UNITY_GRAPHICS=1` keeps the GPU (screenshots).

## Tests
- Domain (`ChunkMesherTests`): empty → no geometry; single block 6 quads; 16×16 slab 6 quads; solid chunk alone 6, surrounded 0; border face culled only by the matching neighbour; different tiles don't merge; checkerboard worst case (12,288 quads); atlas tile per face; **every triangle winds along its normal**; greedy < ⅓ of culled-only faces on generated terrain.
- PlayMode (`VoxelTerrainViewTests`): **DoD**: 64 generated chunks → 35 chunk objects (one per non-empty chunk), renderer count equals chunk count, chunk-sized meshes, triangles ≪ voxels; rebuild replaces objects without leaking.
- EditMode (`VoxelAssetTests`): shader compiles without errors for the active target (Android in the test runner); atlas point-filtered without mipmaps; material wiring.

## Bugs found during validation (fixed)
- Triangle winding for +direction faces initially pointed inward (worked out by hand before running; the per-triangle winding test now guards it).
- Rebuild test counted objects before end-of-frame `Destroy`; it now waits a frame (no actual leak).
