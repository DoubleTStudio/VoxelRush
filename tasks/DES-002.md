# Task: DES-002 — Zone policy and protected structures

## Goal
Who may change what, where. DoD (BACKLOG): unauthorized edits rejected.

## Prerequisites / relevant docs
VR-030/VR-031 (validator, authority), DES-001. GAMEPLAY_RULES (Zones; Multiplayer abuse: enforce protected regions), DESTRUCTION (Policy), SAVE_GAME (WorldMember roles), ADR-004 (editable sandbox, protected infrastructure, isolated race overlay).

## In scope / out of scope
In: `ZoneKind` (Sandbox, RacePreparation, ActiveRace, RaceDestructible, Protected), `WorldRole` (Visitor, Editor, Owner), `ZoneAction` (Place, Remove, Damage), `ZoneMap` (precedence on overlap, default kind, visitor-build flag, `Authorize`), validator/authority integration, new codes `not_permitted` and `race_locked`.
Out: membership/ACL storage and invites (SAVE-004), switching zones with race state (VR-060/061), the race overlay itself (VR-061/SAVE-007), damage sources using `ZoneAction.Damage` (DES-003/004), authoring zones in scenes.

## Rules (`ZoneMap.Authorize`)
| Zone | Place / Remove | Damage |
|---|---|---|
| Protected | never (`protected_zone`) | never |
| ActiveRace | never (`race_locked`) | never |
| RaceDestructible | never (`race_locked`) | allowed (overlay) |
| RacePreparation | Editor/Owner | allowed |
| Sandbox | Editor/Owner; visitors only if `visitorsCanBuild` | allowed |
Overlaps resolve to the highest precedence (Protected > RaceDestructible > ActiveRace > RacePreparation > Sandbox).

## Design notes
- The zone check lives inside the shared `EditValidator` (in place of the bare protected-box list), so client feedback and server enforcement can't diverge. The old constructor maps protected boxes to a `ZoneMap`.
- `WorldAuthority` resolves the actor's role server-side (`roleOf`), defaulting to Editor for the current open test plot; unknown actors are Visitors when a resolver is supplied.

## Tests (`Tests/Domain/World/ZonePolicyTests.cs`)
12-case kind × role × action matrix; public sandbox; overlap precedence; validator reports the same zone reason; **DoD**: through `WorldAuthority`, a visitor in a private sandbox, the owner on the spawn pad and on a live track, and an unknown actor are all rejected while an authorized owner edit succeeds; only that edit changes the world.
